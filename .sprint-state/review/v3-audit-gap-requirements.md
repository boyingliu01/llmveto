# v3 审计可见性：需求稿（R2 修订版）

- 日期：2026-11-28
- 状态：待 delphi 需求评审（R2）
- **定位变更**：从「审计缺口**检测**」降级为「审计**可见性**」

## R1 否决与修订

R1 三席 0% 一致否决，核心论点：

> 路径 B 依赖**攻击者控制的证据**（日志可删、进程可伪造、用户声明是自报）。
> 用这种信号做安全检测违反威胁模型，并制造虚假安全感。
> 要么定义**可信**遥测源（内核审计/eBPF），要么明确归类为"可观测性"而非"安全检测"。

**实测确认**：本机无 `auditd`、无 eBPF 挂载点。可信遥测源在本环境不存在。

**采纳修订**：本切片**明确是可观测性，不是安全检测**。

## 定位（这是本稿最重要的一条）

| 项目 | R1 草案（已废弃） | R2（本稿） |
|---|---|---|
| 名称 | 审计缺口**检测** | 审计**可见性** |
| 承诺 | 发现旁路流量 | 帮助发现**配置遗漏** |
| 威胁模型 | 防恶意绕过 | **不防**；恶意方总能绕过 |
| 文档措辞 | "网关能发现有人在绕过它" | "网关能提示你可能忘了接入" |

**为什么这个区分必须写在代码注释和 README 里，而不只是设计文档**：
一个叫"检测"的功能会让人以为它在防攻击；一个叫"可见性"的功能说的是
"我帮你检查配置"。**前者给人虚假安全感，后者不。**

## 它实际能做什么

**场景**：用户配了三个客户端，其中一个忘记接网关，或者 upgrade 后配置漂移了。
用户以为全都在保护下，实际有一个在裸奔。

**机制**：
1. 用户在 `~/.config/llmveto/watched.json` 声明"我在这台机器上用了这些 agent"：
   ```jsonc
   { "agents": ["claude-code", "codex", "opencode"] }
   ```
2. `llmveto audit` 读取声明，对比最近 evidence 里的 `client` 分布
3. 输出：哪些声明的客户端**没有流量**

**它不做的**：不判断"这些流量是被绕过了还是压根没用"。它只陈述
"你声明了 X 在用，但网关没见过 X 的流量"。

## 会话头路径（保留，定位降级）

A 路径（`x-llmveto-session-id`）**保留**，但**不用于安全判据**：

- 用途：让**同一客户端多次请求**能聚合统计
- 明确**不承诺**：发了头的客户端"一定可信"，不发的"一定可疑"
- 没有头时标 `unlinked`，**不假装能关联**

## 目标（可判定）

1. 能读用户声明（`watched.json`）
2. 能统计 evidence 里各 `client` 的流量分布
3. 能列出"声明了但无流量"的客户端
4. 声明文件缺失/损坏 → 明确状态（不是"无遗漏"）
5. 结果进 `doctor` 可见

## 必须回答（R1 遗留）

### Q1：声明文件读不到时怎么办？

**答**：`doctor` 报 `[SKIP] 未声明监看列表（未启用此功能）`。
不是 PASS——PASS 会被读成"检查过且没问题"。

### Q2：时间窗？

**答**：`audit` 命令默认看**最近 N 天**（默认 7，可配）。
- 声明了但该窗口内毫无流量 → 报告
- 某客户端最后一次流量早于窗口 → 单独标 `stale`，不与"从未见过"混为一谈

不设"实时检测"——这个命令是**用户主动运行**的，不是常驻监控。

### Q3：检出后的 action？

**答**：只输出到 stdout + `doctor` 显示。**不写 evidence**（它不是流量事件，
写进 append-only 的流量链会污染语义）。

## 非目标（对照 R1 已明确删除的）

- ❌ 检测恶意绕过（**做不到**，没有可信遥测）
- ❌ 阻断旁路（物理上碰不到）
- ❌ 常驻监控/实时告警
- ✅ 只做：用户主动运行时，报告配置遗漏

## 验收

| AC | 判据 |
|---|---|
| AC1 | 声明 `["a","b"]`，evidence 只有 `a` 的流量 → 输出 `b` 缺失 |
| AC2 | 声明 `["a"]`，evidence 有 `a` → 无缺失报告 |
| AC3 | `watched.json` 不存在 → `doctor` 显示 SKIP（不是 PASS） |
| AC4 | `watched.json` JSON 损坏 → 明确报错，不静默当空 |
| AC5 | 客户端最后一次流量超出窗口 → 标 `stale`，与"从未见过"区分 |
| AC6 | 无 `x-llmveto-session-id` 的流量标 `unlinked`，不参与会话聚合 |
